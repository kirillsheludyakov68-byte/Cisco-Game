# Адаптивная раскладка окна устройства

Окно устройства (`scenes/DeviceWindow.tscn`) можно развернуть на весь экран или
изменить его размер мышью. Раскладка построена на контейнерах, поэтому вкладки
Physical, Config, Desktop, CLI и Services растягиваются вместе с окном.

## Структура

- `MainPanel` привязан ко всем краям окна и занимает область под строкой вкладок.
- `ContentPanel` заполняет `MainPanel`.
- `PagePhysical` — `VBoxContainer`.
  - `ViewerLayout` — заголовок `Physical Device View`.
  - `ZoomButtons` — кнопки масштаба, центрируются по горизонтали.
  - `PhysicalLayout` — `HBoxContainer`, занимает всё оставшееся место.
    - `ModulesPanel` — фиксированная ширина 200 px.
    - `ViewerPanel` — растягивается по ширине и высоте.
  - `ModuleInfoPanel` — остаётся внизу страницы.
- `DeviceView` заполняет `ViewerPanel`; изображение устройства вписывается в
  область просмотра через `_update_device_base_rect()`.
- Config, Desktop, CLI и Services используют якоря на весь `ContentPanel` и
  поэтому не требуют отдельной раскладки.

## Масштабирование изображения

Для всех устройств, включая PC, изображение вписывается в `DeviceView`.
Кнопка питания PC масштабируется вместе с изображением, чтобы зона нажатия
совпадала с видимой кнопкой.

При изменении размера `DeviceView` вызывает `_on_device_view_resized()`,
пересчитывает базовый прямоугольник и применяет текущий масштаб.

## Размер окна

`DeviceWindow.get_preferred_window_size()` возвращает последний размер окна.
После разворачивания на весь экран следующее устройство откроется в таком же
размере в пределах текущего сеанса.

## Проверка

```powershell
godot --headless --path . res://tests/device_window_layout_test.tscn
```

Тест проверяет:

- заполнение `MainPanel` при большом окне;
- раскладку при минимальном размере;
- заполнение вкладок Config, Desktop, Services и CLI;
- масштабирование и центрирование PC;
- запоминание размера окна.
