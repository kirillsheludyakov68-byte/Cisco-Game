# Cisco Game

## Формат уровня

Уровень описывается JSON-файлом (например, `data/levels/level_1.json`).

### Устройства

```json
{
  "id": "pc1",
  "type": "PC",
  "name": "PC1",
  "position": [500, 300],
  "ip": "192.168.1.1",
  "mask": "255.255.255.0"
}
```

`type` может быть `PC`, `Switch`, `Router` или `AccessPoint`; текстуры находятся в `assets/`.

### Связи

```json
{
  "from": "pc1",
  "to": "sw1",
  "cable": "straight"
}
```

Доступные значения `cable`:

- `straight` — прямой кабель (чёрная сплошная линия);
- `crossover` — кроссовер (оранжевая пунктирная линия);
- `wireless` — беспроводная связь (чёрные палочки через равные промежутки);
- `fiber` — оптоволокно (красная линия).

Для беспроводной связи можно задать задержку подключения в секундах:

```json
{
  "from": "laptop1",
  "to": "ap1",
  "cable": "wireless",
  "delay": 8
}
```

По умолчанию задержка равна 6 секундам. Связь появляется постепенно: палочки проявляются вдоль линии в течение `delay`. После завершения срабатывает сигнал `connection_activated` (у `Connection` и у `NetworkSimulator`), а `NetworkSimulator.find_active_connection(a, b)` начинает возвращать эту связь.

Игрок может создавать такие же связи вручную: выберите кабель на панели сверху — курсор сменится на иконку кабеля — и кликните по двум устройствам.

Если кабель не выбран, клик по устройству открывает окно настроек. Чтобы выйти из режима прокладки кабеля, нажмите выбранную иконку ещё раз; курсор вернётся к обычному виду.

### Очки за уровень

В JSON уровня можно задать параметры начисления очков:

```json
"score": {
  "base": 100,
  "par_time": 120,
  "time_bonus": 50,
  "hint_penalty": 10,
  "min": 25
}
```

- `base` — базовые очки за прохождение;
- `par_time` — время в секундах, за которое даётся максимальный бонус;
- `time_bonus` — максимальный бонус за скорость;
- `hint_penalty` — штраф за каждую использованную подсказку;
- `min` — минимальное количество очков.

Итог: `base + бонус за время - штраф за подсказки`, но не меньше `min`.

Результаты сохраняются в `user://progress.json`. Общий счёт — сумма лучших результатов по уровням, поэтому повторное прохождение не позволяет бесконечно фармить очки. Текущий счёт показывается в шапке панели задания.
