# Cisco Game

## Запуск

1. Откройте папку проекта в Godot 4.7.
2. Нажмите `F5` (или кнопку «Запустить проект»). Главная сцена — `scenes/MainMenu.tscn`.
3. В главном меню выберите «Новая игра», введите имя профиля и откройте первый уровень.

## Главное меню и профили

- «Новая игра» создаёт новый профиль и открывает экран уровней.
- «Продолжить» активно, если существует хотя бы один профиль. Кнопка открывает список профилей, где можно выбрать аккаунт или удалить его.
- «Выход» закрывает игру.
- На экране уровней доступен только первый уровень; остальные показываются с замком.
- Профили и их результаты хранятся в `user://progress.json`. При удалении профиля удаляется и его прогресс.

## Формат уровня

Уровень описывается JSON-файлом (например, `data/levels/level_1.json`).

### Устройства

```json
{
  "id": "pc1",
  "type": "PC",
  "name": "PC1",
  "position": [500, 300],
  "ip": "192.168.1.1",
  "mask": "255.255.255.0"
}
```

`type` может быть `PC`, `Switch`, `Router` или `AccessPoint`; текстуры находятся в `assets/`.

### Связи

```json
{
  "from": "pc1",
  "to": "sw1",
  "cable": "straight"
}
```

Доступные значения `cable`:

- `straight` — прямой кабель (чёрная сплошная линия);
- `crossover` — кроссовер (оранжевая пунктирная линия);
- `wireless` — беспроводная связь (чёрные палочки через равные промежутки);
- `fiber` — оптоволокно (красная линия).

Для беспроводной связи можно задать задержку подключения в секундах:

```json
{
  "from": "laptop1",
  "to": "ap1",
  "cable": "wireless",
  "delay": 8
}
```

По умолчанию задержка равна 6 секундам. Связь появляется постепенно: палочки проявляются вдоль линии в течение `delay`. После завершения срабатывает сигнал `connection_activated` (у `Connection` и у `NetworkSimulator`), а `NetworkSimulator.find_active_connection(a, b)` начинает возвращать эту связь.

Игрок может создавать такие же связи вручную: выберите кабель на панели сверху — курсор сменится на иконку кабеля — и кликните по двум устройствам.

Если кабель не выбран, клик по устройству открывает окно настроек. Чтобы выйти из режима прокладки кабеля, нажмите выбранную иконку ещё раз; курсор вернётся к обычному виду.

### Ping и анимация пакета

Команда `ping <IPv4>` в Command Prompt сначала рассчитывает маршрут по текущей топологии, затем скрывает открытые окна устройств и показывает полёт пакета по кабелям:

- `NetworkSimulator.calculate_ping_route()` возвращает `{ success, path, error_msg }`, где `path` — устройства от источника до цели;
- при ошибке путь обрезается до проблемного устройства: пакет долетает до него, краснеет и исчезает;
- при успехе пакет исчезает с зелёным свечением;
- после анимации и короткой паузы окна устройств возвращаются, а в консоль выводится `Reply from ...`, `Destination host unreachable` или `Request timed out` с причиной ошибки;
- нажатие `Esc` во время анимации отменяет её и сразу возвращает окна.

Анимация реализована отдельно в `scripts/packet_animator.gd`, сцена пакета — `scenes/Packet.tscn`.

### Command Prompt

Вывод команд и текущая введённая строка сохраняются за устройством. Если закрыть окно ПК или само приложение Command Prompt, при повторном открытии сессия восстановится. Она очищается только при выключении ПК кнопкой питания — после следующего включения консоль начинается с приветствия.

### Очки за уровень

В JSON уровня можно задать параметры начисления очков:

```json
"score": {
  "base": 100,
  "par_time": 120,
  "time_bonus": 50,
  "hint_penalty": 10,
  "min": 25
}
```

- `base` — базовые очки за прохождение;
- `par_time` — время в секундах, за которое даётся максимальный бонус;
- `time_bonus` — максимальный бонус за скорость;
- `hint_penalty` — штраф за каждую использованную подсказку;
- `min` — минимальное количество очков.

Итог: `base + бонус за время - штраф за подсказки`, но не меньше `min`.

Результаты сохраняются в профиле игрока в `user://progress.json`. Общий счёт профиля — сумма лучших результатов по уровням, поэтому повторное прохождение не позволяет бесконечно фармить очки. Текущий счёт показывается в шапке панели задания, а также на экранах выбора профиля и уровня.
