# Тесты

## Адаптивная раскладка окна устройства

```powershell
godot --headless --path . res://tests/device_window_layout_test.tscn
```

Тест завершается с кодом `0`, если все проверки прошли, и с кодом `1`, если
есть ошибки. Проверяются:

- растягивание `MainPanel` при большом окне;
- отсутствие зазора между вкладками и рабочей областью;
- положение заголовка и кнопок масштаба над областью просмотра;
- растягивание панели модулей по высоте;
- раскладка при минимальном размере окна;
- заполнение вкладок Config, Desktop, Services и CLI;
- верхний левый угол изображения для всех типов устройств;
- достаточный исходный размер точки доступа;
- отсутствие тени у кнопки помощи;
- сохранение последнего размера окна.
